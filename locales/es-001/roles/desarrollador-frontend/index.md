## Resumen

Los desarrolladores frontend crean las interfaces de usuario de los servicios de salud digital de la organización, como los sitios web y las aplicaciones para pacientes, los formularios en línea y las pantallas que usan los profesionales clínicos y el personal asistencial durante la atención. Escriben código accesible, rápido y seguro que funcione para todo el mundo, incluidas las personas enfermas, angustiadas o que usan dispositivos antiguos, y trabajan en equipos de producto multidisciplinares con diseñadores, investigadores y profesionales clínicos.

## En una organización de atención sanitaria digital

- Muchos usuarios están enfermos, tienen dolor, son mayores o tienen discapacidad, por lo que la accesibilidad y las interfaces sencillas y tranquilas son imprescindibles, no opcionales.
- Una presentación confusa o errónea de la información clínica, como la dosis de un medicamento, un resultado o la hora de una cita, puede causar daño a los pacientes, por lo que el trabajo de frontend sigue el proceso de gestión del riesgo clínico.
- Las interfaces suelen mostrar información sanitaria confidencial, por lo que los desarrolladores diseñan pensando en la privacidad, por ejemplo en dispositivos compartidos y en zonas clínicas concurridas.
- Los profesionales clínicos usan las interfaces con presión de tiempo e interrupciones frecuentes, por lo que las pantallas deben ser rápidas, previsibles y difíciles de malinterpretar.
- Los pacientes acceden a los servicios desde una gran variedad de dispositivos y conexiones, por lo que los servicios usan la mejora progresiva y funcionan en redes lentas.

## Descripción del rol en el UK GDaD PCF (original en inglés)

> A frontend developer designs, builds and improves website software that meets user needs.
> 
> In this role, you will:
> - be responsible for writing clean, accessible code following a progressive enhancement approach
> - create code that is open by default and easy for others to reuse
> - design software which meets user needs and creates meaningful interactions and relationships with users
> - have an understanding of the three fundamental frontend technologies (HTML, CSS and JavaScript)

## Banda 4: Aprendiz de desarrollador frontend

**Nivel del UK GDaD PCF: Apprentice frontend developer**

> An apprentice frontend developer attends certified training and develops skills on the job.
> 
> At this role level, you will:
> - spend a substantial portion of time shadowing others
> - work with other developers to write code and tests
> - write code that follows web standards
> - build your understanding of accessibility
> - build your knowledge
> - develop software which meets user needs

### Responsabilidades

- Aprender el sistema de diseño, los lenguajes y las herramientas del equipo mediante formación estructurada y programación en pareja.
- Crear componentes de interfaz pequeños con supervisión cercana, siguiendo el sistema de diseño de la organización.
- Probar los componentes con tecnologías de apoyo, como los lectores de pantalla, con ayuda de sus colegas.
- Seguir los procedimientos de gobernanza de la información y seguridad clínica al trabajar con datos de prueba y reales.
- Trabajar para obtener una cualificación de aprendizaje o equivalente.

## Banda 6: Desarrollador frontend

**Nivel del UK GDaD PCF: Frontend developer**

> A frontend developer builds software components, primarily in the form of user interfaces.
> 
> At this role level, you will:
> - collaborate and work closely with other disciplines to develop designs and working prototypes based on user needs and in support of organisational aims
> - develop software components that form part of a product to meet user needs
> - write clean, well-tested code that follows web standards
> - coach and mentor more junior colleagues

### Responsabilidades

- Diseñar y crear de forma independiente interfaces accesibles y adaptables para servicios sanitarios, eligiendo los enfoques adecuados.
- Trabajar con diseñadores e investigadores de usuarios para probar prototipos con pacientes, profesionales clínicos y personal asistencial.
- Crear interfaces que llamen a API de datos sanitarios, como servicios HL7 FHIR, y gestionen con seguridad los errores y los datos que falten.
- Participar en talleres de peligros e incorporar controles de seguridad a la interfaz, como pasos de confirmación y avisos claros.
- Proteger la información confidencial en el navegador, por ejemplo gestionando con cuidado las sesiones y la caché en dispositivos compartidos.
- Revisar código y ser mentor de los desarrolladores frontend júnior y aprendices.
