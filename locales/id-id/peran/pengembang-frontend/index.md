## Ringkasan

Pengembang frontend membangun antarmuka pengguna untuk layanan kesehatan digital organisasi, seperti situs web dan aplikasi untuk pasien, formulir daring, dan layar yang dipakai tenaga klinis dan tenaga perawatan selama perawatan. Mereka menulis kode yang dapat diakses, cepat, dan aman yang berfungsi untuk semua orang, termasuk orang yang sedang sakit, cemas, atau memakai perangkat lama, dan mereka bekerja dalam tim produk multidisiplin bersama desainer, peneliti, dan tenaga klinis.

## Di organisasi layanan kesehatan digital

- Banyak pengguna sedang sakit, kesakitan, lanjut usia, atau penyandang disabilitas, sehingga aksesibilitas dan antarmuka yang sederhana dan tenang itu esensial dan bukan pilihan.
- Tampilan informasi klinis yang membingungkan atau salah, seperti dosis obat, hasil pemeriksaan, atau jam janji temu, dapat membahayakan pasien, sehingga pekerjaan frontend mengikuti proses manajemen risiko klinis.
- Antarmuka sering menampilkan informasi kesehatan yang rahasia, sehingga pengembang merancang untuk privasi, misalnya pada perangkat bersama dan di area klinis yang sibuk.
- Tenaga klinis memakai antarmuka di bawah tekanan waktu dan dengan gangguan yang sering, sehingga layar harus cepat, dapat diprediksi, dan sulit disalahbaca.
- Pasien mengakses layanan dengan beragam perangkat dan koneksi, sehingga layanan memakai peningkatan progresif dan berfungsi pada jaringan lambat.

## Deskripsi peran UK GDaD PCF (aslinya dalam bahasa Inggris)

> A frontend developer designs, builds and improves website software that meets user needs.
> 
> In this role, you will:
> - be responsible for writing clean, accessible code following a progressive enhancement approach
> - create code that is open by default and easy for others to reuse
> - design software which meets user needs and creates meaningful interactions and relationships with users
> - have an understanding of the three fundamental frontend technologies (HTML, CSS and JavaScript)

## Pita 4: Pengembang frontend magang

**Tingkat UK GDaD PCF: Apprentice frontend developer**

> An apprentice frontend developer attends certified training and develops skills on the job.
> 
> At this role level, you will:
> - spend a substantial portion of time shadowing others
> - work with other developers to write code and tests
> - write code that follows web standards
> - build your understanding of accessibility
> - build your knowledge
> - develop software which meets user needs

### Tanggung jawab

- Mempelajari sistem desain, bahasa pemrograman, dan perangkat tim melalui pelatihan terstruktur dan kerja berpasangan.

- Mengikuti prosedur tata kelola informasi dan keselamatan klinis saat bekerja dengan data uji dan data langsung.

## Pita 6: Pengembang frontend

**Tingkat UK GDaD PCF: Frontend developer**

> A frontend developer builds software components, primarily in the form of user interfaces.
> 
> At this role level, you will:
> - collaborate and work closely with other disciplines to develop designs and working prototypes based on user needs and in support of organisational aims
> - develop software components that form part of a product to meet user needs
> - write clean, well-tested code that follows web standards
> - coach and mentor more junior colleagues

### Tanggung jawab

- Merancang dan membangun antarmuka yang dapat diakses dan responsif untuk layanan kesehatan secara mandiri, memilih pendekatan yang sesuai.
- Bekerja dengan desainer dan peneliti pengguna untuk menguji prototipe dengan pasien, tenaga klinis, dan tenaga perawatan.
- Membangun antarmuka yang memanggil API data kesehatan, seperti layanan HL7 FHIR, dan menangani kesalahan serta data yang hilang dengan aman.
- Ikut serta dalam lokakarya bahaya dan membangun pengendalian keselamatan ke dalam antarmuka, seperti langkah konfirmasi dan peringatan yang jelas.
- Melindungi informasi rahasia di peramban, misalnya dengan mengelola sesi dan penyimpanan sementara secara hati-hati pada perangkat bersama.
- Meninjau kode dan membimbing pengembang frontend junior dan magang.

### Kualifikasi dan pengalaman yang lazim

- Pengalaman luas dalam memimpin pengembangan frontend di banyak tim atau organisasi.

### Gambaran pita

- **Pengetahuan:** Pengetahuan pakar, serta pemahaman organisasi dan sektor yang luas.
- **Otonomi:** Menetapkan strategi untuk sebuah fungsi; bertanggung jawab kepada seorang direktur.
- **Cakupan:** Sebuah fungsi atau departemen.
- **Kepemimpinan:** Memimpin sebuah fungsi melalui beberapa lapisan manajemen.
- **Akuntabilitas:** Kinerja, tenaga kerja, dan anggaran sebuah fungsi.
