## Resumé

Frontend-udviklere bygger brugergrænsefladerne til organisationens digitale sundhedsservices, såsom websteder og apps til patienter, onlineformularer og skærmbilleder, som klinikere og plejepersonale bruger under plejen. De skriver tilgængelig, hurtig og sikker kode, der fungerer for alle, også for mennesker der er syge, bekymrede eller bruger ældre enheder, og de arbejder i tværfaglige produktteams med designere, forskere og klinikere.

## I en organisation inden for digital sundhed og pleje

- Mange brugere er syge, har smerter, er ældre eller har et handicap, så tilgængelighed og enkle, rolige grænseflader er afgørende og ikke valgfrie.
- En forvirrende eller forkert visning af kliniske oplysninger, såsom en medicindosis, et svar eller et aftaletidspunkt, kan skade patienter, så frontend-arbejde følger processen for klinisk risikostyring.
- Grænseflader viser ofte fortrolige sundhedsoplysninger, så udviklerne designer for privatliv, for eksempel på fælles enheder og i travle kliniske områder.
- Klinikere bruger grænseflader under tidspres og med hyppige afbrydelser, så skærmbilleder skal være hurtige, forudsigelige og svære at misforstå.
- Patienter får adgang til services på en bred vifte af enheder og forbindelser, så services bruger progressiv forbedring og virker på langsomme netværk.

## Rollebeskrivelse i UK GDaD PCF (engelsk original)

> A frontend developer designs, builds and improves website software that meets user needs.
> 
> In this role, you will:
> - be responsible for writing clean, accessible code following a progressive enhancement approach
> - create code that is open by default and easy for others to reuse
> - design software which meets user needs and creates meaningful interactions and relationships with users
> - have an understanding of the three fundamental frontend technologies (HTML, CSS and JavaScript)

## Lønramme 4: Lærling som frontend-udvikler

**Niveau i UK GDaD PCF: Apprentice frontend developer**

> An apprentice frontend developer attends certified training and develops skills on the job.
> 
> At this role level, you will:
> - spend a substantial portion of time shadowing others
> - work with other developers to write code and tests
> - write code that follows web standards
> - build your understanding of accessibility
> - build your knowledge
> - develop software which meets user needs

### Ansvarsområder

- Lære teamets designsystem, sprog og værktøjer gennem struktureret oplæring og parprogrammering.
- Bygge små grænsefladekomponenter under tæt supervision efter organisationens designsystem.
- Teste komponenter med hjælpeteknologier, såsom skærmlæsere, med støtte fra kolleger.
- Følge procedurer for informationsstyring og klinisk sikkerhed, når der arbejdes med test- og live data.
- Arbejde hen imod en lærlingeuddannelse eller tilsvarende uddannelse.

## Lønramme 5: Junior frontend-udvikler

**Niveau i UK GDaD PCF: Junior frontend developer**

> A junior frontend developer learns on the job by delivering software components.
> 
> At this role level, you will:
> - work independently, with guidance from more senior developers, to identify user issues and needs
> - write clean code that follows web standards
> - build your understanding of accessibility
> - build your knowledge
> - develop software which meets user needs

### Ansvarsområder

- Bygge og teste grænsefladefunktioner til services for patienter og for medarbejdere ud fra brugerhistorier med vejledning.
- Bruge organisationens designsystem og mønstre, så services ser ens ud og opfører sig ens.
- Rette tilgængelighedsfejl og kontrollere sider mod standarder for tilgængelighed som WCAG.
- Sikre, at kliniske oplysninger, såsom datoer, doser og svar, vises præcis som specificeret.
- Bidrage med dokumentation til kliniske sikkerhedsbegrundelser, såsom testresultater og skærmbilleder af ændringer.

## Lønramme 6: Frontend-udvikler

**Niveau i UK GDaD PCF: Frontend developer**

> A frontend developer builds software components, primarily in the form of user interfaces.
> 
> At this role level, you will:
> - collaborate and work closely with other disciplines to develop designs and working prototypes based on user needs and in support of organisational aims
> - develop software components that form part of a product to meet user needs
> - write clean, well-tested code that follows web standards
> - coach and mentor more junior colleagues

### Ansvarsområder

- Designe og bygge tilgængelige, responsive grænseflader til sundhedsservices selvstændigt og vælge egnede tilgange.
- Arbejde sammen med designere og brugerforskere om at teste prototyper med patienter, klinikere og plejepersonale.
- Bygge grænseflader, der kalder API'er for sundhedsdata, såsom HL7 FHIR-services, og håndtere fejl og manglende data sikkert.
- Deltage i farerworkshops og bygge sikkerhedskontroller ind i grænsefladen, såsom bekræftelsestrin og klare advarsler.
- Beskytte fortrolige oplysninger i browseren, for eksempel ved at styre sessioner og mellemlagring omhyggeligt på fælles enheder.
- Gennemgå kode og være mentor for junior- og lærlinge-frontend-udviklere.

### Oversigt over lønrammen

- **Viden:** Ekspertviden og bred forståelse af organisationen og sektoren.
- **Selvstændighed:** Fastlægger strategien for en funktion; er ansvarlig over for en direktør.
- **Rækkevidde:** En funktion eller en afdeling.
- **Ledelse:** Leder en funktion gennem flere ledelseslag.
- **Ansvar:** En funktions resultater, arbejdsstyrke og budget.
