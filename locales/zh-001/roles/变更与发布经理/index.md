# 变更与发布经理

> 这是一份面向通用数字医疗卫生机构的示例性参考档案。它不是任何雇主的正式职位说明，其中的岗位评估分数也不是正式评估。

> 本文由人工智能助手从英文翻译而来，尚未经过母语人士审校。引自英国政府数字与数据专业能力框架（UK GDaD PCF）和 ESCO 的内容保留英文原文。

**职族:** [IT 运维](../../#it-运维)  
**职级:** 4, 5, 6  
**UK GDaD PCF 角色:** [Change and release manager](https://understand-digital-data-roles-skills.service.gov.uk/role/change-and-release-manager/)  
**ESCO 职业:** [ICT change and configuration manager](http://data.europa.eu/esco/occupation/3b1ea27c-781c-41eb-821f-214285260dd2) (ISCO-08 2519)

## 概述

变更与发布经理确保对 IT 服务的变更得到评估、批准、排期并安全实施，确保发布得到规划和协调。他们主持变更咨询委员会，负责配置管理数据库，并跨团队和供应商协调发布。在医疗卫生领域，他们确保对临床系统的变更把握好时机并经过测试，以保护患者照护。

## 在数字医疗卫生机构中

- 对临床系统的变更可能伤害患者，因此变更评估包括临床安全审查和来自临床风险管理流程的证据。
- 临床服务每天运行，因此变更窗口要与临床服务商定，并避开其最繁忙的时段。
- 许多变更来自临床系统供应商，即使由供应商控制发布，也必须对其进行评估。
- 紧急安全补丁等紧急变更必须在网络风险与干扰照护的风险之间取得平衡。
- 准确的配置管理数据库能显示一项变更可能影响哪些临床服务。

## 职级 4: 配置分析员

**UK GDaD PCF 级别: Configuration analyst**

> A configuration analyst provides administrative support to the change and release manager, helping to maintain the integrity of the configuration management database (CMDB) and independently solving smaller problems.

### 职责

- 维护配置管理数据库中的记录，包括每个组件所支持的临床服务。
- 对照发现工具检查配置记录，并修复缺口和错误。
- 为变更咨询委员会准备变更记录和议程。
- 回答关于配置项及其相互关系的常规问题。

- **领导力:** 可能督导一个小团队或协调他人的工作。
- **问责:** 交付一项明确的服务或流程。

## 职级 5: 变更与发布分析员

**UK GDaD PCF 级别: Change and release analyst**

> A change and release analyst plans and rolls out software, and designs and carries out procedures for the distribution and installation of changes to systems and services.
> 
> At this role level, you will:
> - undertake analysis after release and set the plan for upcoming changes
> - liaise with DevOps and service designers

### 职责

- 评估变更请求的风险和影响，包括对临床服务和患者安全的影响。
- 规划发布并排期，与临床和运营服务商定变更窗口。
- 检查每项变更是否经过测试、有回滚计划，并在需要时获得临床安全签核。
- 与 DevOps 团队、供应商和服务台协调发布。
- 事后审查发布并规划即将进行的变更。

## 职级 6: 变更与发布经理

**UK GDaD PCF 级别: Change and release manager**

> A change and release manager ensures that technical changes to IT services are adequately assessed for impact, prioritised, scheduled, authorised and implemented. They ensure this is done in line with processes and using appropriate tools. They chair the Change Advisory Board (CAB).
> 
> At this role level, you will:
> - provide an escalation point
> - make decisions for all technical changes
> - co-ordinate releases and interdependencies

### 职责

- 主持变更咨询委员会，在变更影响患者照护时纳入临床和运营代表。
- 决定技术变更，并批准紧急安全补丁等紧急变更。
- 跨内部团队和供应商协调发布及其依赖关系。
- 负责变更、发布和配置管理流程以及配置管理数据库。
- 担任变更冲突和失败变更的上报对象。
- 报告变更成功率、失败变更以及由变更引起的事件，并推动改进。
