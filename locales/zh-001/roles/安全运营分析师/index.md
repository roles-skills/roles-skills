# 安全运营分析师

> 这是一份面向通用数字医疗卫生机构的示例性参考档案。它不是任何雇主的正式职位说明，其中的岗位评估分数也不是正式评估。

> 本文由人工智能助手从英文翻译而来，尚未经过母语人士审校。引自英国政府数字与数据专业能力框架（UK GDaD PCF）和 ESCO 的内容保留英文原文。

**职族:** [网络安全](../../#网络安全)  
**职级:** 5, 6, 7  
**UK GDaD PCF 角色:** 无（本参考资料定义该角色）  
**ESCO 职业:** [cyber incident responder](http://data.europa.eu/esco/occupation/0ce5a9f4-e00a-4bbe-b255-3c63407167a4) (ISCO-08 2529); [ICT security technician](http://data.europa.eu/esco/occupation/a44a1dc5-be08-4840-8bd5-770c4ac1ca6d) (ISCO-08 3512)

## 概述

安全运营分析师监视、调查和应对针对组织系统和数据的网络安全威胁。他们对安全监控工具的警报进行分诊，调查可疑活动，遏制事件，并帮助修复弱点。在医疗卫生领域，快速发现和响应能保护临床服务和保密的患者信息免受勒索软件等攻击。

## 在数字医疗卫生机构中

- 医疗卫生经常成为勒索软件和数据窃取的目标，一次攻击就可能使全组织的临床系统停止运行。
- 隔离服务器或部分网络等遏制决定必须权衡安全风险与对患者照护的影响，因此分析师与临床和运营负责人合作。
- 网络中包括无法运行安全代理或无法快速打补丁的医疗器械和遗留系统，因此分析师依靠网络监控和补偿性控制措施。
- 监控涵盖对患者记录的访问，因此分析师与信息治理部门合作，既帮助发现外部攻击，也帮助发现内部人员的不当访问。
- 安全监控全天候运行，因此分析师可能轮班或参加值班轮换。

## 职级 5: 初级安全运营分析师

初级安全运营分析师在有经验的分析师指导下监控安全警报，使用操作手册进行分诊，并上报事件。

### 职责

- 监控安全监控工具和终端工具的警报，并使用操作手册进行分诊。
- 收集关于网络钓鱼邮件或异常登录等可疑活动的证据并上报。
- 检查员工报告的网络钓鱼邮件，并协助从邮箱中删除恶意邮件。
- 在案件管理工具中准确记录事件和处理行动。
- 运行漏洞扫描，并提醒系统负责人处理到期的修复。

## 职级 6: 安全运营分析师

安全运营分析师调查和遏制安全事件，编写检测规则，并改进组织的安全监控。

### 职责

- 与系统负责人和临床服务合作，调查安全事件、确定其范围并加以遏制。
- 编写和调整检测规则，并根据当前针对医疗卫生的威胁开展威胁狩猎。
- 监控对患者记录的不当访问，并将案例移交给信息治理部门。
- 按风险评估漏洞，包括其对临床服务和医疗器械的影响。
- 在事件后改进操作手册和工具。
- 参加值班轮换，处理非工作时间的安全事件。

## 职级 7: 高级安全运营分析师

高级安全运营分析师领导对重大安全事件的响应，领导威胁狩猎，并指导安全运营团队的工作。

### 职责

- 领导对重大安全事件（包括勒索软件和数据窃取）的技术响应，并与事件管理部门协调。
- 就影响患者照护的遏制决定向临床和运营负责人提供建议。
- 领导威胁狩猎和威胁情报工作，并与医疗卫生安全合作伙伴共享信息。
- 确定检测工程和监控覆盖范围的优先事项，包括医疗器械网络。
- 领导与技术和临床团队一起测试事件响应的演练。
- 辅导和指导安全运营分析师。

### 典型资质与经验

- 在安全运营和事件响应方面拥有丰富经验，相当于研究生文凭水平。
- 相关的高级安全认证，或同等经验。

### 职级概要

- **知识:** 高度发达的专门知识，通常达到硕士水平或同等经验。
- **自主性:** 按组织政策工作；决定如何取得成果；是他人咨询的专家。
- **范围:** 多个产品或服务，或一项专门职能。
- **领导力:** 领导一个团队或一个专业实践领域。
- **问责:** 交付一项服务或专门职能，以及其预算（如有）。
