# Datblygwr pen blaen

> Proffil cyfeirio enghreifftiol yw hwn ar gyfer sefydliad gofal iechyd digidol cyffredinol. Nid yw'n swydd-ddisgrifiad swyddogol ar gyfer unrhyw gyflogwr, ac nid yw ei sgoriau gwerthuso swyddi yn werthusiad ffurfiol.

> Cyfieithwyd y testun hwn o'r Saesneg gan gynorthwyydd deallusrwydd artiffisial, ac nid yw siaradwr Cymraeg brodorol wedi'i adolygu eto. Mae'r derminoleg yn dilyn TermCymru, cronfa dermau Llywodraeth Cymru. Mae dyfyniadau o Fframwaith Gallu Proffesiwn Digidol a Data Llywodraeth y DU ac o ESCO yn aros yn Saesneg.

**Teulu:** [Datblygu meddalwedd](../../#datblygu-meddalwedd)  
**Bandiau:** 4, 5, 6, 7, 8b, 8c  
**Rôl UK GDaD PCF:** [Frontend developer](https://understand-digital-data-roles-skills.service.gov.uk/role/frontend-developer/)  
**Galwedigaethau ESCO:** [web developer](http://data.europa.eu/esco/occupation/c40a2919-48a9-40ea-b506-1f34f693496d) (ISCO-08 2513); [user interface developer](http://data.europa.eu/esco/occupation/866c7813-2c03-47d7-9bdc-192cfbace57c) (ISCO-08 2512)

## Crynodeb

Mae datblygwyr pen blaen yn adeiladu rhyngwynebau defnyddwyr gwasanaethau iechyd digidol y sefydliad, fel gwefannau ac apiau ar gyfer cleifion, ffurflenni ar-lein, a sgriniau y mae clinigwyr a staff gofal yn eu defnyddio yn ystod gofal. Maen nhw'n ysgrifennu cod hygyrch, cyflym, a diogel sy'n gweithio i bawb, gan gynnwys pobl sy'n sâl, yn bryderus, neu'n defnyddio dyfeisiau hŷn, ac maen nhw'n gweithio mewn timau cynnyrch amlddisgyblaethol gyda dylunwyr, ymchwilwyr, a chlinigwyr.

## Mewn sefydliad gofal iechyd digidol

- Mae llawer o ddefnyddwyr yn sâl, mewn poen, yn hŷn, neu'n anabl, felly mae hygyrchedd a rhyngwynebau clir a thawel yn hanfodol yn hytrach na dewisol.
- Gall arddangos gwybodaeth glinigol mewn ffordd ddryslyd neu anghywir, fel dos meddyginiaeth, canlyniad, neu amser apwyntiad, niweidio cleifion, felly mae gwaith pen blaen yn dilyn y broses rheoli risg glinigol.
- Mae rhyngwynebau'n aml yn dangos gwybodaeth iechyd gyfrinachol, felly mae datblygwyr yn dylunio ar gyfer preifatrwydd, er enghraifft ar ddyfeisiau a rennir ac mewn mannau clinigol prysur.
- Mae clinigwyr yn defnyddio rhyngwynebau dan bwysau amser a gydag ymyriadau aml, felly mae'n rhaid i sgriniau fod yn gyflym, yn rhagweladwy, ac yn anodd eu camddarllen.
- Mae cleifion yn cyrraedd gwasanaethau ar ystod eang o ddyfeisiau a chysylltiadau, felly mae gwasanaethau'n defnyddio gwelliant cynyddol ac yn gweithio ar rwydweithiau araf.

## Disgrifiad rôl UK GDaD PCF (y gwreiddiol Saesneg)

> A frontend developer designs, builds and improves website software that meets user needs.
> 
> In this role, you will:
> - be responsible for writing clean, accessible code following a progressive enhancement approach
> - create code that is open by default and easy for others to reuse
> - design software which meets user needs and creates meaningful interactions and relationships with users
> - have an understanding of the three fundamental frontend technologies (HTML, CSS and JavaScript)

## Band 4: Datblygwr pen blaen prentis

**Lefel UK GDaD PCF: Apprentice frontend developer**

> An apprentice frontend developer attends certified training and develops skills on the job.
> 
> At this role level, you will:
> - spend a substantial portion of time shadowing others
> - work with other developers to write code and tests
> - write code that follows web standards
> - build your understanding of accessibility
> - build your knowledge
> - develop software which meets user needs

### Cyfrifoldebau

- Dysgu system ddylunio, ieithoedd, ac offer y tîm drwy hyfforddiant strwythuredig a gweithio mewn parau.
- Adeiladu cydrannau rhyngwyneb bach dan oruchwyliaeth agos, gan ddilyn system ddylunio'r sefydliad.
- Profi cydrannau gyda thechnolegau cynorthwyol, fel darllenwyr sgrin, gyda chymorth gan gydweithwyr.
- Dilyn gweithdrefnau llywodraethiant gwybodaeth a diogelwch clinigol wrth weithio gyda data prawf a data byw.
- Gweithio tuag at brentisiaeth neu gymhwyster cyfatebol.

## Band 6: Datblygwr pen blaen

**Lefel UK GDaD PCF: Frontend developer**

> A frontend developer builds software components, primarily in the form of user interfaces.
> 
> At this role level, you will:
> - collaborate and work closely with other disciplines to develop designs and working prototypes based on user needs and in support of organisational aims
> - develop software components that form part of a product to meet user needs
> - write clean, well-tested code that follows web standards
> - coach and mentor more junior colleagues

### Cyfrifoldebau

- Dylunio ac adeiladu rhyngwynebau hygyrch ac ymatebol ar gyfer gwasanaethau iechyd yn annibynnol, gan ddewis dulliau addas.
- Gweithio gyda dylunwyr ac ymchwilwyr defnyddwyr i brofi prototeipiau gyda chleifion, clinigwyr, a staff gofal.
- Adeiladu rhyngwynebau sy'n galw APIs data iechyd, fel gwasanaethau HL7 FHIR, ac sy'n ymdrin â gwallau a data coll yn ddiogel.
- Cymryd rhan mewn gweithdai peryglon a chynnwys mesurau rheoli diogelwch yn y rhyngwyneb, fel camau cadarnhau a rhybuddion clir.
- Diogelu gwybodaeth gyfrinachol yn y porwr, er enghraifft drwy reoli sesiynau a storfa dros dro yn ofalus ar ddyfeisiau a rennir.
- Adolygu cod a mentora datblygwyr pen blaen iau a phrentis.

- Cynghori uwch arweinwyr ar dechnoleg pen blaen, buddsoddiad mewn system ddylunio, a risgiau rhyngwynebau gwael i ofal.
- Cynrychioli'r sefydliad mewn cymunedau system ddylunio a hygyrchedd ar draws sefydliadau.
- Arwain a datblygu datblygwyr pen blaen ar draws y sefydliad, gan gynnwys recriwtio a llwybrau gyrfa.
