# SFIA levels of responsibility

SFIA (the Skills Framework for the Information Age) is a widely used global framework for digital skills. Its current version is SFIA 9, published in October 2024. SFIA content is © SFIA Foundation and is licensed separately, so this reference names SFIA levels only and does not reproduce SFIA text. See <https://sfia-online.org/> for the framework itself.

## Levels

SFIA has seven levels of responsibility, each with a short name:

| Level | Name |
| --- | --- |
| 1 | Follow |
| 2 | Assist |
| 3 | Apply |
| 4 | Enable |
| 5 | Ensure, advise |
| 6 | Initiate, influence |
| 7 | Set strategy, inspire, mobilise |

Each level is described through generic attributes: autonomy, influence, complexity, knowledge, and business skills and behavioural factors. Separately, each SFIA skill is defined at the levels where it applies.

## How this reference uses SFIA

Each band in [`data/bands.yaml`](../../data/bands.yaml) records the typical SFIA level of responsibility for that band:

| Band | SFIA level |
| --- | --- |
| 1, 2 | 1 |
| 3 | 2 |
| 4 | 2–3 |
| 5 | 3 |
| 6 | 4 |
| 7 | 5 |
| 8a | 5–6 |
| 8b, 8c | 6 |
| 8d | 6–7 |
| 9 | 7 |

The band competency outlines in this reference (knowledge, autonomy, scope, leadership, and accountability) are original. They were written to line up with SFIA's generic attributes at the matching level.

This mapping lets organisations that already use SFIA see roughly where each band sits. SFIA levels describe the responsibility of a person or role. They are not pay bands, and one SFIA level can span more than one band.
