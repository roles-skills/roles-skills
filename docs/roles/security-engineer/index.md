# Security engineer

> This is an illustrative reference profile for a generic digital health care organisation. It is not an official job description for any employer, and its job evaluation scores are not a formal evaluation.

**Family:** [Cyber security](../../#cyber-security)  
**Bands:** 6, 7, 8a  
**UK GDaD PCF role:** none (this reference defines the role)  
**ESCO occupations:** [ICT security administrator](http://data.europa.eu/esco/occupation/0464b062-cea6-4164-b10d-956c61956ae7) (ISCO-08 2529)

## Summary

Security engineers design, build, and run the technical security controls that protect the organisation's systems, data, and users. They work on identity and access, endpoint and network protection, encryption, logging, and cloud security, and help product and infrastructure teams build security in. In health care, they protect clinical systems and patient data while keeping access fast for clinicians at the point of care.

## In a digital health care organisation

- Security controls must not get in the way of urgent care, so engineers design strong authentication that still works quickly on shared clinical workstations.
- Medical devices and legacy clinical systems often cannot be patched or run security software, so engineers design network segmentation and compensating controls.
- Ransomware is a major threat to health care, so engineers harden systems, protect backups, and limit how far an attack can spread.
- Clinical systems are often supplied and supported by third parties, so engineers assess supplier security and control their remote access.
- Changes to security controls on clinical systems go through change management and, where needed, clinical safety review.

## Band 6: Security engineer

A security engineer builds, configures, and maintains security controls and tools, and helps teams fix security weaknesses.

### Responsibilities

- Build and maintain security controls, such as endpoint protection, firewalls, email security, and security logging.
- Configure identity and access controls, including multi-factor authentication and privileged access.
- Help infrastructure and product teams fix vulnerabilities and harden systems to agreed standards.
- Segment networks to protect medical devices and legacy systems, working with infrastructure and clinical engineering teams.
- Review the security of new systems and supplier remote access before they go live.
- Take part in the on-call rota to support security incident response.

## Band 7: Senior security engineer

A senior security engineer designs and leads the delivery of significant security controls, and advises teams on secure design.

### Responsibilities

- Design and lead the delivery of security controls, such as privileged access management, security monitoring, and backup protection.
- Advise product and infrastructure teams on secure design for clinical and patient-facing services.
- Design compensating controls for medical devices and other systems that cannot be patched.
- Assess the security of suppliers and their products, including cloud services.
- Support the response to serious security incidents with technical expertise and recovery plans.
- Coach security engineers and share good practice across teams.

## Band 8a: Lead security engineer

A lead security engineer sets the technical direction for security engineering, and makes sure controls work together across the organisation.

### Responsibilities

- Set the technical direction and standards for security controls across the organisation.
- Lead the security design for major programmes, such as moves to cloud hosting or a new electronic patient record.
- Make sure controls protect against ransomware and support fast, safe recovery of clinical systems.
- Balance security with clinical usability, working with clinical leads on access and authentication.
- Advise the cyber security manager on technical risk and investment.
- Lead and develop security engineers.
