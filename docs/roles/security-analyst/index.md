**UK GDaD PCF role:** none (this reference defines the role)  
**ESCO occupations:** [cyber incident responder](http://data.europa.eu/esco/occupation/0ce5a9f4-e00a-4bbe-b255-3c63407167a4) (ISCO-08 2529); [ICT security technician](http://data.europa.eu/esco/occupation/a44a1dc5-be08-4840-8bd5-770c4ac1ca6d) (ISCO-08 3512)

## Summary

Security operations analysts watch for, investigate, and respond to cyber security threats to the organisation's systems and data. They triage alerts from security monitoring tools, investigate suspicious activity, contain incidents, and help fix weaknesses. In health care, fast detection and response protects clinical services and confidential patient information from attacks such as ransomware.

## In a digital health care organisation

- Health care is a frequent target for ransomware and data theft, and one attack can stop clinical systems across the organisation.
- Containment decisions, such as isolating a server or part of the network, must weigh security risk against the effect on patient care, so analysts work with clinical and operational leads.
- Networks include medical devices and legacy systems that cannot run security agents or be patched quickly, so analysts rely on network monitoring and compensating controls.
- Monitoring covers access to patient records, so analysts help detect inappropriate access by insiders as well as external attacks, working with information governance.
- Security monitoring runs around the clock, so analysts may work shifts or on-call rotas.

## Band 5: Junior security operations analyst

A junior security operations analyst monitors security alerts, triages them using runbooks, and escalates events, with guidance from experienced analysts.

### Responsibilities

- Monitor alerts from security monitoring and endpoint tools, and triage them using runbooks.
- Gather evidence about suspicious activity, such as phishing emails or unusual logins, and escalate it.
- Check phishing emails reported by staff, and help remove malicious emails from mailboxes.
- Record events and actions accurately in the case management tool.
- Run vulnerability scans and remind system owners about fixes that are due.

## Band 6: Security operations analyst

A security operations analyst investigates and contains security incidents, writes detection rules, and improves the organisation's security monitoring.

### Responsibilities

- Investigate security incidents, work out their scope, and contain them, working with system owners and clinical services.
- Write and tune detection rules, and run threat hunts based on current threats to health care.
- Monitor for inappropriate access to patient records, and pass cases to information governance.
- Assess vulnerabilities by risk, including their effect on clinical services and medical devices.
- Improve runbooks and tools after incidents.
- Take part in the on-call rota for out-of-hours security incidents.

## Band 7: Senior security operations analyst

A senior security operations analyst leads the response to significant security incidents, leads threat hunting, and guides the work of the security operations team.

### Responsibilities

- Lead the technical response to significant security incidents, including ransomware and data theft, and coordinate with incident management.
- Advise clinical and operational leaders on containment decisions that affect patient care.
- Lead threat hunting and threat intelligence work, and share information with health care security partners.
- Set priorities for detection engineering and monitoring coverage, including for medical device networks.
- Lead exercises that test incident response with technical and clinical teams.
- Coach and guide security operations analysts.
