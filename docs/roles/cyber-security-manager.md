# Cyber security manager

> This is an illustrative reference profile for a generic digital health care organisation. It is not an official job description for any employer, and its job evaluation scores are not a formal evaluation.

**Family:** [Cyber security](../index.md#cyber-security)  
**Bands:** 8a, 8b, 8c, 8d  
**UK GDaD PCF role:** none (this reference defines the role)  
**ESCO occupations:** [cybersecurity risk manager](http://data.europa.eu/esco/occupation/7754d570-9519-48c2-b1c9-8e165f8bca0f) (ISCO-08 2529); [chief ICT security officer](http://data.europa.eu/esco/occupation/276ba420-ef09-4a0e-b215-2c2e2f80ad28) (ISCO-08 2529)

## Summary

Cyber security managers lead the organisation's approach to protecting its systems, data, and services from cyber threats. They set security policy, manage cyber risk, oversee security operations and engineering, lead the response to major cyber incidents, and build a security-aware culture. In health care, they make sure clinical services can keep running safely, and recover quickly, when an attack happens.

## In a digital health care organisation

- A cyber attack on a health care organisation can stop clinical systems and put patients at risk, so cyber security is part of patient safety and business continuity.
- Health care organisations often have to meet sector cyber security standards and report serious incidents to the relevant authorities.
- Clinical staff need fast access to systems, so security policies are designed with clinicians and tested for usability.
- Security depends on many suppliers, including clinical system suppliers and shared services, so supplier assurance is a core part of the role.
- Medical devices and legacy systems create long-lasting risks that are managed with clinical engineering and clinical safety teams.

## Band 8a: Cyber security manager

A cyber security manager runs the cyber security function, or a major part of it, managing cyber risk, security operations, and assurance.

### Responsibilities

- Run security operations, vulnerability management, and assurance work, and report on their performance.
- Maintain the cyber risk register, and make sure risks to clinical services are assessed and owned.
- Write and maintain security policies and standards, and check that they are followed.
- Lead the response to cyber incidents, working with incident management and with clinical and operational leaders.
- Run security awareness training and phishing exercises for all staff, including clinical staff.
- Line manage security analysts and engineers.

## Band 8b: Senior cyber security manager

A senior cyber security manager leads cyber security across several teams, manages assurance against sector standards, and runs the organisation's security improvement programme.

### Responsibilities

- Lead cyber security teams across operations, engineering, and assurance.
- Run the organisation's cyber security improvement programme and manage its budget.
- Manage assurance against sector cyber security standards and ISO/IEC 27001 controls, and prepare evidence for audits.
- Lead the response to major cyber incidents, and plan and test recovery with business continuity and clinical leads.
- Assess the security of suppliers and shared services, and agree security requirements in contracts.
- Advise programme boards on the security risks of new clinical and digital services.

## Band 8c: Head of cyber security

A head of cyber security sets the organisation's cyber security strategy and is accountable for its cyber risk management, security operations, and response to major incidents.

### Responsibilities

- Set the cyber security strategy, in line with the organisation's digital and clinical strategies.
- Advise the board and executive team on cyber risk, risk appetite, and investment.
- Lead the organisation's response to major cyber incidents, including communication with regulators, partners, and the public.
- Build a security culture in which all staff, including clinicians, understand threats and report them.
- Represent the organisation in health care cyber security networks and with partner organisations.
- Lead and develop the cyber security function, and manage its budget.

## Band 8d: Chief information security officer

A chief information security officer has corporate responsibility for cyber security across the organisation, and often across partner organisations that share its services.

### Responsibilities

- Hold corporate responsibility for cyber security, and report on it to the board.
- Set the security risk appetite with the board, and make sure it shapes decisions across the organisation.
- Lead cyber security across shared services and partner organisations, where the organisation provides them.
- Direct the organisation's response to the most serious cyber incidents, working with the executive team and the relevant authorities.
- Shape cyber security practice across the health and care sector by working with partners and sector bodies.
- Lead the security function and hold budgets across several services.
